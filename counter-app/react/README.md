# カウンターアプリ - React 版

極力シンプルな React カウンターアプリです。

## 機能

- ボタンをクリックするとカウントが 1 つずつ増加します

## 開発環境の起動

```bash
cd counter-app/react
npm install
npm run dev
```

## ファイル構成

- `src/App.jsx` - メインの React コンポーネント
- `src/main.jsx` - アプリケーションのエントリーポイント
- `index.html` - HTML テンプレート
- `package.json` - 依存関係とスクリプト
